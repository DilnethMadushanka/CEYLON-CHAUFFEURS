# 🚀 Ceylon Chauffeurs — Deployment & Production Launch Guide

This document outlines the deployment roadmap, architecture options, and step-by-step instructions for publishing **Ceylon Chauffeurs** live on the web.

---

## 📌 Tomorrow's Action Plan (මීළඟ පියවර)

1. **Step 1: Free Instant Hosting (GitHub Pages / Vercel)**
   - **GitHub Pages**: Go to GitHub Repository -> Settings -> Pages -> Source: `main` branch -> Save.
   - **Live URL**: `https://dilnethmadushanka.github.io/CEYLON-CHAUFFEURS/`
   - **Admin Portal URL**: `https://dilnethmadushanka.github.io/CEYLON-CHAUFFEURS/admin/`

2. **Step 2: Instant Booking Email Notifications (Web3Forms / EmailJS)**
   - Connect free email notification service so every booking form submission sends an instant alert to the company Gmail / Concierge email.
   - Zero server cost (Free forever tier).

3. **Step 3: Custom Domain Setup (Optional / Recommended)**
   - Purchase `.com` domain (e.g., `ceylonchauffeur.com` or `ceylonchauffeurs.com`) via Namecheap / Cloudflare (~$10–$12/year, approx. LKR 3,500/year).
   - Point DNS CNAME to GitHub Pages or Vercel with free automatic SSL (HTTPS).

4. **Step 4: Professional Business Email Setup (Free via Zoho Mail)**
   - Configure `info@ceylonchauffeur.com` / `bookings@ceylonchauffeur.com` for free using Zoho Mail Custom Domain plan (Up to 5 users free).

5. **Step 5: Cloud Database Sync for Admin Portal (Optional)**
   - Connect Supabase (PostgreSQL) or Google Sheets API so all international bookings sync centrally to `/admin` from any device around the world.
